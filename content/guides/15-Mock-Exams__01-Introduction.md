### What this is
Three full mock exams with solutions to practise exam conditions: 2 hours, hands-on, multiple clusters/contexts.

### How to use them
1. Do them in one sitting with only `kubernetes.io/docs` for help.
2. Start each task with the given `kubectl config use-context ...`.
3. Triage: easy and high-weight tasks first; flag tasks that take more than 8 minutes.
4. Use `--dry-run=client -o yaml`; verify every result.
5. Afterwards read the solutions only for tasks you missed, and redo them a day later.

### Pass mark
66%. A mock score above ~75% on first attempt means you're ready.
