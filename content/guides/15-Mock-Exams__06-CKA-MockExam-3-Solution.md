### How to use the solutions
Go through each question: do you know why that solution works?
1. Re-run the commands against your lab.
2. Note the fastest route (imperative vs YAML, `kubectl explain`, docs snippets).
3. Write down gaps and revisit the matching section guide.

### Tip
If a solution uses a feature you haven't used (JSONPath, `etcdutl`, `kubeadm certs`) practise it separately before the real exam.
